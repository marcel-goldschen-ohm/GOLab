# GOLab
Goldschen-Ohm lab software.

# Setup Python
1. Install [miniforge](https://github.com/conda-forge/miniforge).
2. Create a python environment named "golab" to work in: `conda create -n golab python`
3. Activate your golab environment: `conda activate golab`
4. Install some basic python packages: e.g., `pip install ipykernel numpy pandas xarray zarr scipy matplotlib seaborn`
5. Install [Visual Studio Code](https://code.visualstudio.com).
6. In VSCode install the Python and Jupyter extensions.
7. Open a `*.ipynb` file in VSCode and select the python interpreter associated with your golab environment.
